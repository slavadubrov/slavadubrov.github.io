Einrichtung eines MacBook für AI Engineering: macOS-Tools, Python, Docker und Terminal-Arbeitsabläufe

Dies ist meine Checkliste, um eine frisch installierte macOS-Maschine in einen Arbeitsplatz für AI Engineering zu verwandeln: Kommandozeilen-Tools, Homebrew, Python, Docker, Standardeinstellungen des Terminals sowie Editor-Einrichtungen.

Kurzfassung: So richte ich mein neues MacBook ein: Homebrew, Python mit uv, das mitgelieferte Zsh zusammen mit Oh My Zsh und Powerlevel10k, Docker, meine Editoren sowie lokale AI-Tools. Halten Sie die Befehle und Dotfiles unter Versionskontrolle, damit die Einrichtung wiederholt werden kann.

1. Installation der Xcode Command Line Tools

xcode-select --install

Dadurch wird ein Dialog geöffnet, der Sie durch den Installationsprozess führt.

2. Installation von Homebrew

Homebrew ist das Paketverwaltungstool, das ich für alle weiteren Elemente auf dieser Liste verwende:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Der Installer erklärt, welche Änderungen vorgenommen werden, und bittet um Bestätigung. Auf Apple Silicon verwendet Homebrew standardmäßig /opt/homebrew. Folgen Sie dem am Ende angezeigten Befehl brew shellenv – Homebrew stellt den Befehl nicht automatisch in jedem Shell zur Verfügung.

3. Installation der Kerntools

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Grob nach ihrer Funktion gruppiert:

Python-Umgebung

Bevor ich zu uv wechselte, nutzte ich pyenv als Grundlage für die Verwaltung meiner Python-Umgebung. Heute übernimmt uv diesen täglichen Workflow für mich, einschließlich der Installation von Python und der Verwaltung von Projektumgebungen.

  • uv installiert Python-Versionen und verwaltet Projektumgebungen, Abhängigkeiten, Befehle sowie Lockfiles.
  • pyenv ist optional. Ich verwende es nur dann, wenn ich einen aus Quellen kompilierten Interpreter oder spezielle CPython-Konfigurationsoptionen benötige, die die vorgefertigten Distributionen von uv nicht bieten.

Installieren Sie pyenv separat, falls Sie diesen aus Quellen kompilierten Pfad benötigen:

brew install pyenv

Systembibliotheken

  • openssl bietet Unterstützung für SSL/TLS-Kryptografie.
  • readline ermöglicht die Textbearbeitung in der Kommandozeile.
  • sqlite3 ist eine leichte eingebettete Datenbank.
  • xz und zlib dienen der Datenkompression.

Produktivitätswerkzeuge

  • htop ist ein visueller Monitor für System und Prozesse.
  • tmux verwaltet mehrere Terminal-Sessions.
  • ncdu analysiert die Datenträgernutzung interaktiv.
  • gitmoji fügt Emojis zu Commit-Nachrichten hinzu.
  • pandoc konvertiert Dokumente zwischen verschiedenen Formaten.

Weitere Informationen zu uv finden Sie in meinem Kurzleitfaden zur Verwaltung von Python unter macOS mit uv.

4. Wahl des Terminals

Der standardmäßige macOS Terminal reicht aus. Ich habe jahrelang iTerm2 verwendet und bin kürzlich auf Warp umgestiegen – ein auf Rust basierendes Terminal mit integrierten AI-Funktionen. Die Wahl ist persönlich; die anschließende Einrichtung hängt nicht davon ab.

Optional: Einrichtung von iTerm2

Falls Sie weiterhin iTerm2 nutzen, ändere ich stets diese beiden Einstellungen:

Aktivierung der natürlichen Textbearbeitung

  1. Preferences → Profiles → Keys → Key Mappings
  2. Klicken Sie auf das Dropdown-Menü „Presets…“
  3. Wählen Sie „Natural Text Editing“

Auswahl eines Farbthemas

  1. Durchsuchen Sie die Themen unter iTerm2-Color-Schemes.
  2. Wechseln Sie zu Einstellungen → Profile → Farben → Farbvorlagen…
  3. Klicken Sie auf Importieren und wählen Sie das heruntergeladene Theme aus.

5. Einrichtung von Zsh

macOS enthält bereits Zsh und verwendet es als Standard‑Login‑Shell. Ich nutze die mitgelieferte /bin/zsh; Homebrew’s Zsh sollte nur dann installiert werden, wenn eine speziellere, neuere Version benötigt wird.

Überprüfen Sie die installierte Version von Zsh sowie Ihre aktuelle Login‑Shell:

echo "$SHELL"
command -v zsh
zsh --version

Falls Zsh installiert ist, aber nicht als Login‑Shell ausgewählt wurde, wechseln Sie auf die mitgelieferte Kopie:

chsh -s /bin/zsh

Öffnen Sie nach dem Ändern der Login‑Shell ein neues Terminal.

Oh My Zsh fügt zusätzlich die Standardeinstellungen sowie ein Plugin‑System hinzu, das ich verwende. Der offizielle Installer lautet:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Das Projekt empfiehlt, unbekannte Installer vor dem Ausführen genauer zu prüfen. Zudem wird dokumentiert, dass eine vorhandene .zshrc während der Installation in .zshrc.pre-oh-my-zsh umbenannt wird.

6. Hinzufügen von Zsh‑Plugins

Bearbeiten Sie Ihre ~/.zshrc, um diese Plugins zu laden:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Entfernen Sie pyenv aus der Liste der Plugins, falls Sie die optionale Installation von pyenv übersprungen haben.

Beschreibungen zu allen Plugins finden Sie in der Oh My Zsh Plugins Wiki.

Die letzten beiden Plugins müssen separat installiert werden:

  • zsh-autosuggestions schlägt beim Tippen Befehle aus Ihrer Historie vor.
  • zsh-syntax-highlighting färbt die eingegebenen Befehle, wodurch Tippfehler leichter erkennbar sind.

Befolgen Sie dazu die Installationsanleitungen in den jeweiligen Repositories.

7. Thematisierung mit Powerlevel10k

Powerlevel10k ist das Zsh‑Theme, das ich verwende. Es zeigt im Prompt den Arbeitsverzeichnis, den git‑Status sowie die aktive Python‑Umgebung und verfügt über einen interaktiven Assistenten zur Anpassung des Aussehens. Die Installationsanleitung befindet sich auf der GitHub-Seite.

Schriftarten in anderen Editoren

Falls Sie VSCode oder einen anderen Editor mit integriertem Terminal verwenden, stellen Sie die Schriftart des Terminals so ein, dass die Icons von Powerlevel10k korrekt angezeigt werden:

  1. Öffnen Sie die Einstellungen Ihres Editors.
  2. Suchen Sie nach terminal.integrated.fontFamily.
  3. Wählen Sie MesloLGS NF aus (diese Schriftart wird zusammen mit Powerlevel10k installiert).

Eine vollständige Anleitung zur Einstellung der Schriftarten finden Sie in der Powerlevel10k Font Guide.

8. Editor und AI‑Assistenten

Ich arbeite stets mit einem IDE sowie einem oder zwei laufenden AI‑Tools daneben.

IDEs

  • Cursor – ein Fork von VSCode mit integriertem AI‑Pair‑Programming.
  • VSCode – das Tool mit dem umfangreichen Erweiterungskatalog.

AI‑Assistenten

  • OpenAI Codex – OpenAI’s Programmier‑Agent.
  • Claude – Anthropics Assistent; ich nutze ihn bei schwierigeren Aufgaben.

Heutzutage verwende ich meist Cursor zusammen mit Codex und Claude Code in Parallel.

9. Weitere Tools

Einige zusätzliche Tools, die ich auf jedem Rechner installiere:

  • GitHub Desktop – ein visueller Git‑Client, wenn ich nicht direkt die CLI nutzen möchte.
  • Docker Desktop – der Container‑Runtime, den ich verwende; Podman Desktop ist eine Alternative.
  • Ollama oder LM Studio – zum Lokalbetrieb von großen Sprachmodellen auf dem Mac.

10. Die Einrichtung

Das ist das, was ich auf jedem neuen MacBook vor Beginn der eigentlichen Arbeit installiere. Anpassen nach eigenem Ermessen.

Wichtige Erkenntnisse

  1. Es handelt sich um eine persönliche Konfiguration, keine minimale oder universelle macOS-Basis. Entfernen Sie alles, was Sie nicht benötigen.
  2. Die mitgelieferte /bin/zsh reicht für diese Einrichtung aus. Installieren Sie nur dann Homebrews Zsh, wenn Sie eine speziellere, neuere Version benötigen.
  3. In meinem täglichen Arbeitsablauf übernimmt uv nun die Verwaltung von Python-Installationen sowie Projektumgebungen. pyenv bleibt optional, falls man selbst kompilierte oder angepasste CPython-Interpreter verwendet.
  4. Dokumentieren Sie die Installationsbefehle, die nicht sensiblen Konfigurationsdateien, Editor-Erweiterungen sowie die Speicherorte der Modelle, damit die anschließende Einrichtung reibungslos abläuft.
