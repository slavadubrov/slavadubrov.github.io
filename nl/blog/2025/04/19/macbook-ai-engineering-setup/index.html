MacBook-setup voor AI engineering: macOS-tools en workflow

Dit is mijn checklist om een nieuwe macOS-installatie om te vormen tot een werkstation voor AI engineering: command-line tools, Homebrew, Python, Docker, terminaldefaults en editorconfiguratie.

TL;DR: Homebrew, Python met uv, de meegeleverde Zsh met Oh My Zsh en Powerlevel10k, Docker, mijn editors en lokale AI-tools. Houd de commands en dotfiles bij in version control, zodat de setup reproduceerbaar is.

1. Xcode Command Line Tools installeren

xcode-select --install

Hiermee open je een dialoogvenster dat je door de installatie leidt.

2. Homebrew installeren

Homebrew is de package manager die ik gebruik voor de rest van deze lijst:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

De installer legt uit wat er wordt gewijzigd en vraagt om bevestiging. Op Apple Silicon gebruikt Homebrew standaard /opt/homebrew. Voer de brew shellenv-command uit die aan het einde wordt weergegeven; Homebrew voegt brew niet zelf toe aan de PATH van je shell.

3. De core tools installeren

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Grofweg gegroepeerd naar functie:

Python environment

Voordat ik uv gebruikte, gebruikte ik pyenv om mijn Python environments te beheren. uv dekt die dagelijkse workflow nu voor mij af.

  • uv installeert Python-versies en beheert project environments, dependencies, commands en lockfiles.
  • pyenv is optioneel. Ik gebruik het alleen wanneer ik een source-built interpreter of aangepaste CPython-buildopties nodig heb die de prebuilt distributions van uv niet bieden.

Installeer de nieuwste Python-versie die door uv wordt beheerd:

uv python install

Deze command installeert de nieuwste Python-versie die uv op het moment van de setup beschikbaar heeft. Gebruik voor een project-specifieke versie de pinning-workflow in de gekoppelde uv-guide.

Installeer pyenv afzonderlijk wanneer je die source-buildroute nodig hebt:

brew install pyenv

System libraries

  • openssl biedt cryptografische ondersteuning voor SSL/TLS.
  • readline voegt text editing op de command line toe.
  • sqlite3 is een lichtgewicht embedded database.
  • xz en zlib bieden datacompressie.

Productivity tools

  • htop is een visuele system- en process monitor.
  • tmux beheert meerdere terminal sessions.
  • ncdu analyseert interactief het diskgebruik.
  • gitmoji voegt emoji’s toe aan commit messages.
  • pandoc converteert documenten tussen formaten.

Zie mijn Quick-Guide voor Python-beheer op macOS met uv voor meer informatie over uv zelf.

4. Een terminal kiezen

De standaard macOS Terminal is prima. Jarenlang gebruikte ik iTerm2, maar onlangs ben ik overgestapt op Warp, een op Rust gebaseerde terminal met ingebouwde AI-features. De keuze is persoonlijk; de rest van de setup is er niet van afhankelijk.

Optioneel: iTerm2 instellen

Als je iTerm2 blijft gebruiken, zijn dit de twee settings die ik altijd wijzig:

Natural text editing inschakelen

  1. Preferences → Profiles → Keys → Key Mappings
  2. Klik op de dropdown Presets…
  3. Selecteer “Natural Text Editing”

Een color theme kiezen

  1. Bekijk themes op iTerm2-Color-Schemes
  2. Preferences → Profiles → Colors → Color Presets…
  3. Klik op Import en selecteer je gedownloade theme

5. Zsh instellen

macOS bevat Zsh al en gebruikt het als de standaard login shell. Ik gebruik de meegeleverde /bin/zsh; installeer Homebrew’s Zsh alleen wanneer je een specifieke, nieuwere upstream-versie nodig hebt.

Controleer de geïnstalleerde Zsh en je huidige login shell:

echo "$SHELL"
command -v zsh
zsh --version

Als Zsh wel is geïnstalleerd maar niet als je login shell is geselecteerd, schakel dan over naar de meegeleverde versie:

chsh -s /bin/zsh

Open na het wijzigen van de login shell een nieuwe terminal.

Oh My Zsh voegt daar de defaults en het plugin-systeem aan toe die ik gebruik. De officiële installer is:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Het project raadt aan een onbekende installer te inspecteren voordat je die uitvoert. Het documenteert ook dat een bestaande .zshrc tijdens de installatie wordt hernoemd naar .zshrc.pre-oh-my-zsh.

6. Zsh-plugins toevoegen

Installeer de twee externe plugins in de custom plugin directory van Oh My Zsh:

git clone https://github.com/zsh-users/zsh-autosuggestions "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions"
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting"

Bewerk je ~/.zshrc om deze plugins te laden:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Laat zsh-syntax-highlighting als laatste in deze array staan.

Verwijder pyenv uit de pluginlijst als je de optionele pyenv-installatie hebt overgeslagen.

Beschrijvingen van al deze plugins staan in de Oh My Zsh plugins wiki.

De laatste twee vereisen een afzonderlijke installatie:

  • zsh-autosuggestions stelt tijdens het typen commands uit je history voor.
  • zsh-syntax-highlighting kleurt commands tijdens het typen, waardoor typefouten makkelijker opvallen.

Volg de installatie-instructies in elke repository.

7. Instellen als theme met Powerlevel10k

Powerlevel10k is de Zsh-theme die ik gebruik. In de prompt toont deze de working directory, git-status en actieve Python environment. Daarnaast heeft de theme een interactieve wizard om het uiterlijk aan te passen. De installatie-instructies staan op de GitHub-pagina.

Het Powerlevel10k-font installeren

Als je VS Code met een geïntegreerde terminal gebruikt, installeer dan het aanbevolen font voordat je het terminalfont instelt. Hierdoor kunnen de Powerlevel10k-icons correct worden weergegeven. Met p10k configure kun je het font automatisch in iTerm2 installeren. Download en installeer voor andere terminals de vier TTF-bestanden uit de Powerlevel10k-fontguide.

Stel in VS Code het terminalfont in op MesloLGS NF:

  1. Open de settings van je editor
  2. Zoek naar terminal.integrated.fontFamily
  3. Stel dit in op MesloLGS NF

De volledige fontconfiguratie staat in de Powerlevel10k-fontguide.

8. Editor- en AI-assistants

Ik eindig altijd met één IDE open en daarnaast een of twee AI-tools die draaien.

IDEs

  • Cursor — een VS Code-fork met ingebouwde AI pair programming
  • VS Code — de editor met de enorme extension-catalogus

AI-assistants

  • OpenAI Codex — de coding agent van OpenAI
  • Claude — de assistant van Anthropic; mijn eerste keuze voor complexere taken

Tegenwoordig zijn dat Cursor met Codex en Claude Code die parallel draaien.

9. De rest

Een paar extra’s die ik op elke machine installeer:

  • GitHub Desktop — visuele Git-client wanneer ik niet naar de CLI wil
  • Docker Desktop — de container runtime die ik gebruik; Podman Desktop is een alternatief
  • Ollama of LM Studio — LLMs lokaal op de Mac draaien

10. Dat is de setup

Alles hierboven installeer ik op elke nieuwe MacBook voordat ik aan het echte werk begin. Pas de setup naar eigen voorkeur aan.

Belangrijkste punten

  1. Dit is een persoonlijke setup, geen minimale of universele macOS-baseline. Verwijder alles wat je niet gebruikt.
  2. De meegeleverde /bin/zsh is voldoende voor deze setup. Installeer Homebrew’s Zsh alleen wanneer je een specifieke, nieuwere upstream-versie nodig hebt.
  3. uv beheert in mijn dagelijkse workflow inmiddels de Python-installatie en project environments. pyenv blijft optioneel voor source-built of aangepaste CPython-interpreters.
  4. Documenteer install commands, dotfiles zonder secrets, editor extensions en model locations, zodat de volgende setup mechanisch verloopt.
