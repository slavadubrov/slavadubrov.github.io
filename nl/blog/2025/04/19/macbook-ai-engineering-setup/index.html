Instellingen voor MacBook voor AI-engineering: macOS-hulpmiddelen, Python, Docker en terminalworkflow

Dit is mijn controlelijst om een nieuwe macOS-installatie om te zetten in een werkstation voor AI-engineering: command-line-hulpmiddelen, Homebrew, Python, Docker, standaardinstellingen van de terminal en instellingen van de editor.

Kort samengevat: Dit is de configuratie die ik gebruik op een nieuwe MacBook: Homebrew, Python met uv, de geïnstalleerde Zsh aangevuld met Oh My Zsh en Powerlevel10k, Docker, mijn editors en lokale AI-hulpmiddelen. Zorg ervoor dat de commando’s en dotfiles onder versiebeheer vallen, zodat de configuratie herhaalbaar blijft.

1. Installeer de Xcode Command Line Tools

xcode-select --install

Hierdoor wordt een dialoogweergave geopend die je stap voor stap door de installatie leidt.

2. Installeer Homebrew

Homebrew is het pakketbeheersysteem dat ik gebruik voor alle overige elementen op deze lijst:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

De installer legt uit wat er gaat veranderen en vraagt om bevestiging. Op Apple Silicon maakt Homebrew standaard gebruik van /opt/homebrew. Volg het commando dat aan het einde wordt weergegeven via brew shellenv; Homebrew zorgt er niet automatisch voor dat het commando in elke shell beschikbaar is.

3. Installeer de kernhulpmiddelen

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Grotendeels gegroepeerd naar hun functie:

Python-omgeving

Voorheen gebruikte ik pyenv als basis voor het beheren van mijn Python-omgeving. Tegenwoordig dekt uv al die dagelijkse taken voor mij, inclusief de installatie van Python en het beheren van projectomgevingen.

  • uv installeert Python-versies en beheert projectomgevingen, afhankelijkheden, commando’s en lockfiles.
  • pyenv is optioneel. Ik gebruik het alleen wanneer ik een brongebouwde interpreter of aangepaste CPython-opties nodig heb die niet in de vooraf gebouwde distributies van uv zitten.

Installeer pyenv apart wanneer je die brongebouwde opties nodig hebt:

brew install pyenv

Systeembibliotheken

  • openssl biedt ondersteuning voor SSL/TLS-cryptografie.
  • readline voegt tekstbewerking in de command-line toe.
  • sqlite3 is een lichtgewicht ingebouwde database.
  • xz en zlib zorgen voor gegevenscompressie.

Productiviteitshulpmiddelen

  • htop is een visuele monitor voor het systeem en processen.
  • tmux beheert meerdere terminalsessies.
  • ncdu analyseert interactief de schijfgebruik.
  • gitmoji voegt emoji’s toe aan commitberichten.
  • pandoc converteert documenten tussen verschillende formaten.

Voor meer informatie over uv zelf, zie mijn Quick-Guide op het beheren van Python op macOS met uv.

4. Kies een terminal

De standaard macOS Terminal is voldoende. Ik gebruikte jarenlang iTerm2 en ben onlangs overgestapt op Warp, een op Rust gebaseerde terminal met ingebouwde AI-functies. De keuze is persoonlijk; de rest van de configuratie is hier niet van afhankelijk.

Optioneel: Configuratie van iTerm2

Als je bij iTerm2 blijft, zijn dit de twee instellingen die ik altijd aanpas:

Activeren van natuurlijke tekstbewerking

  1. Preferences → Profiles → Keys → Key Mappings
  2. Klik op de dropdown Presets…
  3. Kies “Natural Text Editing”

Kiezen van een kleurenthema

  1. Blader door thema’s op iTerm2-Color-Schemes.
  2. Preferences → Profiles → Colors → Color Presets…
  3. Klik op Import en selecteer het gedownloade thema.

5. Zsh instellen

macOS bevat al Zsh en gebruikt deze als standaard inlogshell. Ik maak gebruik van de meegeleverde /bin/zsh; installeer Homebrew’s Zsh alleen wanneer je een specifieke, nieuwere versie nodig hebt.

Controleer de geïnstalleerde Zsh en je huidige inlogshell:

echo "$SHELL"
command -v zsh
zsh --version

Als Zsh geïnstalleerd is maar niet is geselecteerd als inlogshell, schakel dan over op de meegeleverde versie:

chsh -s /bin/zsh

Start een nieuwe terminal nadat je de inlogshell hebt gewijzigd.

Oh My Zsh voegt de standaardinstellingen en het plugin-systeem toe die ik gebruik. De officiële installer is:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Het project raadt aan om een onbekende installer eerst te controleren voordat je hem uitvoert. Er wordt ook vermeld dat een bestaande .zshrc tijdens de installatie wordt hernoemd naar .zshrc.pre-oh-my-zsh.

6. Zsh-plugins toevoegen

Editeer je ~/.zshrc om deze plugins te laden:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Verwijder pyenv uit de lijst met plugins als je de optionele pyenv-installatie hebt overgeslagen.

Beschrijvingen van al deze plugins zijn te vinden in de Oh My Zsh plugins wiki.

De laatste twee vereisen een aparte installatie:

  • zsh-autosuggestions stelt commando’s voor op basis van je historiek terwijl je typt.
  • zsh-syntax-highlighting kleurt commando’s terwijl je typt, waardoor fouten gemakkelijker zichtbaar zijn.

Volg de installatie-instructies in elk repository.

7. Thematiseren met Powerlevel10k

Powerlevel10k is het Zsh-thema dat ik gebruik. Het toont de werkmap, de git-status en de actieve Python-omgeving in de prompt, en beschikt over een interactieve wizard om het uiterlijk aan te passen. De installatie-instructies staan op de GitHub pagina.

Schriftsoorten in andere editors

Als je VSCode of een andere editor met een geïntegreerde terminal gebruikt, stel dan de terminal-schriftsoort in zodat de Powerlevel10k-ico’s correct weergegeven worden:

  1. Open de instellingen van je editor.
  2. Zoek naar terminal.integrated.fontFamily.
  3. Stel dit in op MesloLGS NF (geïnstalleerd samen met Powerlevel10k).

Een volledige configuratie van de schriftsoorten staat beschreven in de Powerlevel10k font guide.

8. Editor en AI-assistenten

Ik gebruik altijd één IDE open, samen met één of twee AI-hulpprogramma’s ernaast.

IDE’s

  • Cursor — een fork van VSCode met ingebouwd AI-pair programming.

AI-assistenten

  • OpenAI Codex — OpenAI’s coderingsagent.
  • Claude — Anthropic’s assistent; ik gebruik hem voor complexere taken.

9. Overige tools

Enkele extra tools die ik op elke machine installeer:

  • GitHub Desktop — een visuele Git-client wanneer ik niet via de CLI wil werken.
  • Docker Desktop — de container-runtime die ik gebruik; Podman Desktop is een alternatief.
  • Ollama of LM Studio — om LLM’s lokaal op de Mac uit te voeren.

10. Dat is de instelling

Dit is wat ik op elk nieuw MacBook installeer voordat ik aan echt werk begin. Pas het naar eigen smaak aan.

Belangrijkste punten

  1. Dit betreft een persoonlijke instelling, geen minimale of universele macOS-basis. Verwijder alles wat je niet gebruikt.
  2. De meegeleverde /bin/zsh is voldoende voor deze configuratie. Installeer alleen de Zsh van Homebrew wanneer je een specifieke, nieuwere versie nodig hebt.
  3. In mijn dagelijkse workflow beheert uv nu de installatie van Python en de projectomgevingen. pyenv blijft optioneel voor handgemaakte of aangepaste CPython-interpreters.
  4. Houd de installatiecommando’s, dotfiles zonder gevoelige informatie, editorextensies en locaties van modellen gedocumenteerd, zodat de volgende configuratie eenvoudig kan worden uitgevoerd.
