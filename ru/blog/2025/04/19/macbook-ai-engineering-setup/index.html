Настройка MacBook для AI-инжиниринга: инструменты и рабочий процесс в macOS

Viacheslav Dubrov

2025-04-19 · Обновлено 2026-08-16 · 4 мин · Инструменты разработчика

Автоматический перевод Эта статья была автоматически переведена с оригинальной английской версии.

Это мой чеклист для превращения чистой установки macOS в рабочую станцию для AI-инжиниринга: инструменты командной строки, Homebrew, Python, Docker, настройки терминала по умолчанию и редактора.

Коротко: Homebrew, Python с uv, встроенный Zsh с Oh My Zsh и Powerlevel10k, Docker, мои редакторы и локальные AI-инструменты. Храните команды и дотфайлы в системе контроля версий, чтобы настройку можно было воспроизвести.

1. Установите Xcode Command Line Tools

xcode-select --install

Откроется диалоговое окно с пошаговой установкой.

2. Установите Homebrew

Homebrew — пакетный менеджер, который я использую для всего остального в этом списке:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Установщик объясняет, какие изменения будут внесены, и запрашивает подтверждение. На Apple Silicon Homebrew по умолчанию использует /opt/homebrew. Выполните команду brew shellenv, напечатанную в конце: Homebrew не добавляет brew в PATH вашей оболочки автоматически.

3. Установите основные инструменты

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Примерная группировка по назначению:

Среда Python

До перехода на uv я использовал pyenv для управления средами Python. Теперь uv закрывает мой повседневный рабочий процесс.

  • uv устанавливает версии Python и управляет окружениями проектов, зависимостями, командами и lock-файлами.
  • pyenv необязателен. Я использую его только когда нужен интерпретатор, собранный из исходников, или кастомные параметры сборки CPython, которых нет в предсобранных дистрибутивах uv.

Установите последнюю версию Python, доступную через uv:

uv python install

Эта команда устанавливает последнюю версию Python, доступную uv на момент настройки. Для версии, специфичной для проекта, используйте workflow фиксации версии из руководства по uv.

Установите pyenv отдельно, если нужен сценарий со сборкой из исходников:

brew install pyenv

Системные библиотеки

  • openssl обеспечивает поддержку криптографии SSL/TLS.
  • readline добавляет редактирование текста в командной строке.
  • sqlite3 — лёгкая встроенная база данных.
  • xz и zlib обеспечивают сжатие данных.

Инструменты для продуктивности

  • htop — визуальный монитор системы и процессов.
  • tmux управляет несколькими терминальными сессиями.
  • ncdu интерактивно анализирует использование диска.
  • gitmoji добавляет эмодзи в сообщения коммитов.
  • pandoc конвертирует документы между форматами.

Подробнее о самом uv см. в моём кратком руководстве по управлению Python в macOS с помощью uv.

4. Выберите терминал

Стандартный терминал macOS вполне подходит. Я много лет использовал iTerm2, а недавно перешёл на Warp — терминал на Rust со встроенными AI-функциями. Выбор субъективен; последующая настройка от него не зависит.

Опционально: настройка iTerm2

Если вы остаетесь на iTerm2, я всегда меняю две настройки:

Включите естественное редактирование текста

  1. Preferences → Profiles → Keys → Key Mappings
  2. Нажмите на выпадающий список Presets…
  3. Выберите “Natural Text Editing”

Выберите цветовую тему

  1. Просмотрите темы на странице iTerm2-Color-Schemes
  2. Preferences → Profiles → Colors → Color Presets…
  3. Нажмите Import и выберите скачанную тему

5. Настройте Zsh

macOS уже включает Zsh и использует его как оболочку входа по умолчанию. Я использую встроенный /bin/zsh; устанавливайте Zsh из Homebrew только если вам нужна конкретная более новая версия из upstream.

Проверьте установленный Zsh и текущую оболочку входа:

echo "$SHELL"
command -v zsh
zsh --version

Если Zsh установлен, но не выбран как оболочка входа, переключитесь на встроенную копию:

chsh -s /bin/zsh

После смены оболочки входа откройте новый терминал.

Oh My Zsh добавляет поверх него используемые мной настройки по умолчанию и систему плагинов. Официальный установщик:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Проект рекомендует проверить незнакомый установщик перед запуском. В документации также указано, что существующий .zshrc во время установки переименовывается в .zshrc.pre-oh-my-zsh.

6. Добавьте плагины Zsh

Установите два внешних плагина в пользовательский каталог плагинов Oh My Zsh:

git clone https://github.com/zsh-users/zsh-autosuggestions "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions"
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting"

Отредактируйте ~/.zshrc, чтобы подключить эти плагины:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Оставьте zsh-syntax-highlighting последним в этом массиве.

Если вы пропустили опциональную установку pyenv, удалите pyenv из списка плагинов.

Описания всех этих плагинов есть в wiki плагинов Oh My Zsh.

Последние два требуют отдельной установки:

  • zsh-autosuggestions предлагает команды из истории по мере ввода.
  • zsh-syntax-highlighting подсвечивает команды при вводе, благодаря чему опечатки легче заметить.

Следуйте инструкциям по установке в каждом репозитории.

7. Настройте тему Powerlevel10k

Powerlevel10k — используемая мной тема Zsh. Она показывает в промпте рабочий каталог, статус git и активное окружение Python, а также содержит интерактивный мастер настройки внешнего вида. Инструкции по установке доступны на странице GitHub.

Установите шрифт Powerlevel10k

Если вы используете VS Code со встроенным терминалом, установите рекомендуемый шрифт до настройки шрифта терминала. Это позволит корректно отображать иконки Powerlevel10k. p10k configure может автоматически установить шрифт в iTerm2. Для других терминалов скачайте и установите четыре TTF-файла из руководства по шрифтам Powerlevel10k.

В VS Code установите для терминала шрифт MesloLGS NF:

  1. Откройте настройки редактора
  2. Найдите terminal.integrated.fontFamily
  3. Установите значение MesloLGS NF

Полная настройка шрифта описана в руководстве по шрифтам Powerlevel10k.

8. Редактор и AI-ассистенты

В итоге у меня всегда открыт один IDE, а рядом запущены один или два AI-инструмента.

IDE

  • Cursor — форк VS Code со встроенным AI pair programming
  • VS Code — редактор с огромным каталогом расширений

AI-ассистенты

  • OpenAI Codex — coding agent от OpenAI
  • Claude — ассистент Anthropic; к нему я обращаюсь для более сложных задач

Сейчас это Cursor с параллельно запущенными Codex и Claude Code.

9. Остальное

Несколько дополнительных инструментов, которые я устанавливаю на каждый компьютер:

  • GitHub Desktop — визуальный Git-клиент, когда не хочется переходить в CLI
  • Docker Desktop — используемый мной рантайм контейнеров; Podman Desktop — альтернатива
  • Ollama или LM Studio — запуск LLM локально на Mac

10. Настройка завершена

Всё перечисленное выше я устанавливаю на каждый новый MacBook до начала полноценной работы. Остальное настройте под себя.

Главные выводы

  1. Это персональная настройка, а не минимальный или универсальный baseline для macOS. Уберите всё, чем не пользуетесь.
  2. Для этой настройки достаточно встроенного /bin/zsh. Устанавливайте Zsh из Homebrew только если нужна конкретная более новая версия из upstream.
  3. В моём повседневном workflow uv теперь отвечает за установку Python и окружения проектов. pyenv остаётся опциональным инструментом для интерпретаторов, собранных из исходников, или кастомных сборок CPython.
  4. Документируйте команды установки, дотфайлы без секретов, расширения редактора и расположение моделей, чтобы следующая настройка выполнялась механически.
