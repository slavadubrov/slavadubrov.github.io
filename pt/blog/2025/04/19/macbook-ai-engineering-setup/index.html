Configuração de um MacBook para AI Engineering: ferramentas e fluxo de trabalho no macOS

Viacheslav Dubrov

2025-04-19 · Atualizado 2026-08-16 · 5 min · Ferramentas de desenvolvimento

Tradução automática Este artigo foi traduzido automaticamente a partir da versão original em inglês.

Este é o meu checklist para transformar uma instalação nova do macOS numa workstation de AI engineering: ferramentas de linha de comandos, Homebrew, Python, Docker, predefinições do terminal e configuração do editor.

TL;DR

Homebrew, Python com uv, o Zsh incluído com Oh My Zsh e Powerlevel10k, Docker, os meus editores e ferramentas de AI locais. Mantenha os comandos e os dotfiles sob controlo de versões para que a configuração seja repetível.

1. Instalar as Command Line Tools do Xcode

xcode-select --install

Isto abre uma caixa de diálogo que orienta o processo de instalação.

2. Instalar o Homebrew

O Homebrew é o package manager que uso para tudo o resto nesta lista:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

O instalador explica o que vai alterar e pede confirmação. Em Apple Silicon, o Homebrew usa /opt/homebrew por predefinição. Execute o comando brew shellenv apresentado no fim; o Homebrew não adiciona brew ao PATH da sua shell automaticamente.

3. Instalar as ferramentas essenciais

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Agrupadas, aproximadamente, pela sua finalidade:

Ambiente Python

Antes de adotar o uv, usava o pyenv para gerir os meus ambientes Python. Atualmente, o uv cobre esse fluxo de trabalho diário.

  • uv instala versões do Python e gere ambientes de projeto, dependências, comandos e lockfiles.
  • pyenv é opcional. Uso-o apenas quando preciso de um interpreter compilado a partir do código-fonte ou de opções de compilação personalizadas do CPython que as distribuições pré-compiladas do uv não disponibilizam.

Instale a versão mais recente do Python gerida pelo uv:

uv python install

Este comando instala a versão mais recente do Python disponível no uv no momento da configuração. Para uma versão específica de um projeto, use o fluxo de pinning indicado no guia do uv associado.

Instale o pyenv separadamente quando precisar desse fluxo baseado numa compilação a partir do código-fonte:

brew install pyenv

Bibliotecas do sistema

  • openssl fornece suporte criptográfico para SSL/TLS.
  • readline acrescenta edição de texto na linha de comandos.
  • sqlite3 é uma base de dados incorporada leve.
  • xz e zlib fornecem compressão de dados.

Ferramentas de produtividade

  • htop é um monitor visual do sistema e dos processos.
  • tmux gere várias sessões de terminal.
  • ncdu analisa interativamente a utilização do disco.
  • gitmoji acrescenta emojis às mensagens de commit.
  • pandoc converte documentos entre formatos.

Para saber mais sobre o próprio uv, consulte o meu guia rápido sobre a gestão do Python no macOS com uv.

4. Escolher um terminal

O Terminal predefinido do macOS é perfeitamente adequado. Usei o iTerm2 durante anos e mudei recentemente para o Warp, um terminal baseado em Rust com funcionalidades de AI integradas. A escolha é pessoal; nenhum dos passos seguintes depende dela.

Opcional: configuração do iTerm2

Se optar por continuar com o iTerm2, há duas definições que altero sempre:

Ativar a edição natural de texto

  1. Preferences → Profiles → Keys → Key Mappings
  2. Clique no menu pendente Presets…
  3. Selecione “Natural Text Editing”

Escolher um tema de cores

  1. Consulte os temas em iTerm2-Color-Schemes
  2. Preferences → Profiles → Colors → Color Presets…
  3. Clique em Import e selecione o tema transferido

5. Configurar o Zsh

O macOS já inclui o Zsh e utiliza-o como shell de login predefinida. Uso o /bin/zsh incluído; instale o Zsh do Homebrew apenas quando precisar de uma versão upstream mais recente específica.

Verifique o Zsh instalado e a shell de login atual:

echo "$SHELL"
command -v zsh
zsh --version

Se o Zsh estiver instalado mas não estiver selecionado como shell de login, mude para a cópia incluída:

chsh -s /bin/zsh

Abra um novo terminal depois de alterar a shell de login.

O Oh My Zsh acrescenta os valores predefinidos e o sistema de plugins que uso. O instalador oficial é:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

O projeto recomenda inspecionar um instalador desconhecido antes de o executar. Documenta também que um .zshrc existente é renomeado para .zshrc.pre-oh-my-zsh durante a instalação.

6. Adicionar plugins ao Zsh

Instale os dois plugins externos no diretório de plugins personalizados do Oh My Zsh:

git clone https://github.com/zsh-users/zsh-autosuggestions "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions"
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting"

Edite o seu ~/.zshrc para carregar estes plugins:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Mantenha zsh-syntax-highlighting em último lugar neste array.

Remova pyenv da lista de plugins se tiver ignorado a instalação opcional do pyenv.

As descrições de todos estes plugins estão na wiki de plugins do Oh My Zsh.

Os dois últimos requerem uma instalação separada:

  • zsh-autosuggestions sugere comandos do seu histórico enquanto escreve.
  • zsh-syntax-highlighting colore os comandos enquanto escreve, facilitando a deteção de erros tipográficos.

Siga as instruções de instalação de cada repositório.

7. Personalizar com o Powerlevel10k

O Powerlevel10k é o tema de Zsh que uso. Apresenta o diretório de trabalho, o estado do git e o ambiente Python ativo na prompt, além de disponibilizar um wizard interativo para ajustar o aspeto. As instruções de instalação estão na página do GitHub.

Instalar o tipo de letra do Powerlevel10k

Se usar o VS Code com um terminal integrado, instale o tipo de letra recomendado antes de configurar o tipo de letra do terminal. Isto permite apresentar os ícones do Powerlevel10k. p10k configure pode instalar automaticamente o tipo de letra no iTerm2. Noutros terminais, transfira e instale os quatro ficheiros TTF do guia de tipos de letra do Powerlevel10k.

No VS Code, defina o tipo de letra do terminal como MesloLGS NF:

  1. Abra as definições do editor
  2. Procure terminal.integrated.fontFamily
  3. Defina-o como MesloLGS NF

A configuração completa do tipo de letra está no guia de tipos de letra do Powerlevel10k.

9. O resto

Alguns extras que instalo em todas as máquinas:

  • GitHub Desktop — cliente visual de Git quando não quero recorrer à CLI
  • Docker Desktop — o runtime de contentores que uso; o Podman Desktop é uma alternativa
  • Ollama ou LM Studio — executar LLMs localmente no Mac

10. É esta a configuração

Tudo o que está acima é instalado em cada MacBook novo antes de começar trabalho a sério. Ajuste ao seu gosto.

Principais conclusões

  1. Esta é uma configuração pessoal, não uma baseline mínima ou universal do macOS. Remova tudo o que não utiliza.
  2. O /bin/zsh incluído é suficiente para esta configuração. Instale o Zsh do Homebrew apenas quando precisar de uma versão upstream mais recente específica.
  3. Atualmente, o uv gere a instalação do Python e os ambientes de projeto no meu fluxo de trabalho diário. O pyenv continua a ser opcional para interpreters compilados a partir do código-fonte ou interpreters CPython personalizados.
  4. Mantenha documentados os comandos de instalação, os dotfiles sem segredos, as extensões do editor e as localizações dos modelos, para que a próxima configuração seja mecânica.
