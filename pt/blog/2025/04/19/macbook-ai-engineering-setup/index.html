Configuração do MacBook para Engenharia de IA: Ferramentas do macOS, Python, Docker e Fluxo de Trabalho no Terminal

Esta é a minha lista de verificação para transformar uma instalação fresca do macOS numa estação de trabalho para engenharia de IA: ferramentas da linha de comandos, Homebrew, Python, Docker, configurações padrão do terminal e ajustes no editor.

TL;DR: Esta é a configuração que uso num novo MacBook: Homebrew, Python com o uv, o Zsh incluído com Oh My Zsh e Powerlevel10k, Docker, os meus editores e ferramentas locais de IA. Mantenha os comandos e ficheiros de configuração sob controlo de versões para garantir que a configuração seja reprodutível.

1. Instalar as Ferramentas de Linha de Comandos do Xcode

xcode-select --install

Isto abre uma caixa de diálogo que o orienta ao longo do processo de instalação.

2. Instalar o Homebrew

Homebrew é o gestor de pacotes que utilizo para tudo o resto nesta lista:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

O instalador explica quais alterações serão feitas e solicita confirmação. Em Apple Silicon, o Homebrew utiliza /opt/homebrew por predefinição. Siga o comando brew shellenv exibido no final; o Homebrew não torna automaticamente o comando disponível em todos os shells.

3. Instalar as ferramentas essenciais

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Agrupadas de forma aproximada conforme a sua função:

Ambiente Python

Antes de adotar o uv, utilizava o pyenv como base para a gestão do ambiente Python. Atualmente, o uv cobre esse fluxo de trabalho diário, incluindo a instalação do Python e a gestão dos ambientes de projeto.

  • uv instala versões do Python e gere os ambientes de projeto, dependências, comandos e ficheiros de bloqueio.
  • pyenv é opcional. Utilizo-o apenas quando preciso de um interpretador compilado a partir da fonte ou de opções de compilação personalizadas do CPython que as distribuições pré-compiladas do uv não oferecem.

Instale o pyenv separadamente se precisar desse método de compilação a partir da fonte:

brew install pyenv

Bibliotecas do sistema

  • openssl fornece suporte à criptografia SSL/TLS.
  • readline adiciona funcionalidades de edição de texto na linha de comandos.
  • sqlite3 é uma base de dados embutida leve.
  • xz e zlib fornecem compressão de dados.

Ferramentas de produtividade

  • htop é um monitor visual de sistema e processos.
  • tmux gere múltiplas sessões de terminal.
  • ncdu analisa o uso do disco de forma interativa.
  • gitmoji adiciona emojis às mensagens de commit.
  • pandoc converte documentos entre formatos.

Para mais informações sobre uv em si, consulte o meu Guia Rápido para Gerir Python no macOS com uv.

4. Escolher um terminal

O Terminal padrão do macOS já é suficiente. Utilizei iTerm2 durante anos e mudei recentemente para Warp, um terminal baseado em Rust com funcionalidades integradas de IA. A escolha é pessoal; nenhuma das etapas seguintes depende disso.

Opcional: Configuração do iTerm2

Se continuar a usar o iTerm2, estas são as duas configurações que sempre altero:

Ativar a edição de texto natural

  1. Preferências → Perfis → Teclas → Mapeamentos de Teclas
  2. Clique na lista suspensa “Predefinições…”
  3. Selecione “Edição de Texto Natural”

Escolher um tema de cor

  1. Navegue pelos temas em iTerm2-Color-Schemes
  2. Preferências → Perfis → Cores → Predefinições de cor…
  3. Clique em “Importar” e selecione o tema que descarregou

5. Configurar o Zsh

O macOS já inclui o Zsh e utiliza‑o como shell de login padrão. Eu uso a versão incluída com o sistema operativo /bin/zsh; instale a versão do Zsh do Homebrew apenas quando precisar de uma versão mais recente específica.

Verifique qual é o Zsh instalado e qual o seu shell de login atual:

echo "$SHELL"
command -v zsh
zsh --version

Se o Zsh estiver instalado mas não estiver selecionado como shell de login, mude para a cópia incluída:

chsh -s /bin/zsh

Abra um novo terminal após alterar o shell de login.

Oh My Zsh adiciona as predefinições e o sistema de plugins que utilizo. O seu instalador oficial encontra‑se em:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

O projeto recomenda examinar cuidadosamente qualquer instalador desconhecido antes de o executar. Documenta também que um .zshrc existente é renomeado para .zshrc.pre-oh-my-zsh durante a instalação.

6. Adicionar plugins ao Zsh

Edite o seu ~/.zshrc para carregar estes plugins:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Remova pyenv da lista de plugins se tiver ignorado a instalação opcional do pyenv.

As descrições de todos eles encontram‑se na wiki de plugins do Oh My Zsh.

Os dois últimos requerem instalação separada:

  • zsh-autosuggestions sugere comandos com base no histórico enquanto digita.
  • zsh-syntax-highlighting colore os comandos à medida que os escreve, facilitando a deteção de erros de digitação.

Siga as instruções de instalação de cada repositório.

7. Personalizar com Powerlevel10k

Powerlevel10k é o tema do Zsh que utilizo. Ele exibe o diretório de trabalho, o estado do git e o ambiente Python ativo no prompt, e dispõe de um assistente interativo para ajustar a aparência. As instruções de instalação encontram‑se na página do GitHub.

Fontes noutros editores

Se utilizar o VSCode ou outro editor com terminal integrado, defina a fonte do terminal para que os ícones do Powerlevel10k sejam exibidos corretamente:

  1. Abra as configurações do editor.
  2. Procure por terminal.integrated.fontFamily.
  3. Defina‑a como MesloLGS NF (instalada juntamente com o Powerlevel10k).

A configuração completa das fontes encontra‑se no guia de fontes do Powerlevel10k.

8. Editores e assistentes de IA

Eu costumo ter sempre um IDE aberto e um ou dois ferramentas de IA em execução ao lado dele.

IDEs

  • Cursor — uma versão modificada do VSCode com programação em parceria com IA integrada.
  • VSCode — aquele com o vasto catálogo de extensões.

Assistentes de IA

  • OpenAI Codex — o agente de programação da OpenAI.
  • Claude — o assistente da Anthropic; é o que utilizo para tarefas mais complexas.

Atualmente, uso o Cursor com o Codex e o Claude Code em paralelo.

9. Outros recursos

Alguns complementos que instalo em todos os meus computadores:

  • GitHub Desktop — cliente visual para Git, quando não quero recorrer à linha de comando.
  • Docker Desktop — o motor de containers que utilizo; Podman Desktop é uma alternativa.
  • Ollama ou LM Studio — para executar modelos de linguagem localmente no Mac.

10. Essa é a configuração inicial

É isto que instalo em cada novo MacBook antes de começar a trabalhar efetivamente. Ajuste conforme a sua preferência.

Principais pontos a reter

  1. Trata‑se de uma configuração pessoal, e não de um ponto de partida mínimo ou universal para o macOS. Remova tudo o que não utilizar.
  2. O /bin/zsh incluído é suficiente para esta configuração. Instale apenas o Zsh do Homebrew quando precisar de uma versão mais recente específica.
  3. Atualmente, o uv gere a instalação do Python e os ambientes de projeto no meu fluxo de trabalho diário. O pyenv continua sendo opcional para interpretadores CPython compilados manualmente ou personalizados.
  4. Mantenha documentados os comandos de instalação, os ficheiros .dot sem informações sensíveis, as extensões do editor e as localizações dos modelos, para que a próxima configuração seja feita de forma mecânica.
