Configuración de MacBook para ingeniería de IA: herramientas de macOS, Python, Docker y flujo de trabajo en la terminal

Este es mi checklist para convertir una instalación nueva de macOS en una estación de trabajo para ingeniería de IA: herramientas de línea de comandos, Homebrew, Python, Docker, configuraciones predeterminadas de la terminal y configuración del editor.

Resumen: Esta es la configuración que uso en un nuevo MacBook: Homebrew, Python con uv, el Zsh incluido con Oh My Zsh y Powerlevel10k, Docker, mis editores y herramientas locales de IA. Mantenga los comandos y archivos de configuración bajo control de versiones para que la configuración sea reproducible.

1. Instalar las Herramientas de Línea de Comandos de Xcode

xcode-select --install

Esto abre un diálogo que guía al usuario durante la instalación.

2. Instalar Homebrew

Homebrew es el gestor de paquetes que utilizo para todo lo demás en esta lista:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

El instalador explica qué cambios se realizarán y solicita confirmación. En Apple Silicon, Homebrew utiliza /opt/homebrew por defecto. Siga el comando brew shellenv que se muestra al final; Homebrew no hace que el comando esté disponible automáticamente en todas las shells.

3. Instalar las herramientas básicas

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Aproximadamente agrupadas según su función:

Entorno de Python

Antes de adoptar uv, utilizaba pyenv como base para la gestión de entornos de Python. Actualmente, uv cubre ese flujo de trabajo cotidiano, incluyendo la instalación de Python y la gestión de entornos de proyecto.

  • uv instala versiones de Python y gestiona entornos de proyecto, dependencias, comandos y archivos de bloqueo.
  • pyenv es opcional. Solo lo uso cuando necesito un intérprete compilado desde código fuente u opciones de compilación personalizadas de CPython que las distribuciones precompiladas de uv no ofrecen.

Instale pyenv por separado si necesita esa vía de compilación desde código fuente:

brew install pyenv

Bibliotecas del sistema

  • openssl proporciona soporte para criptografía SSL/TLS.
  • readline añade funcionalidades de edición de texto en la línea de comandos.
  • sqlite3 es una base de datos incrustada ligera.
  • xz y zlib ofrecen compresión de datos.

Herramientas de productividad

  • htop es un monitor visual del sistema y de procesos.
  • tmux gestiona múltiples sesiones de terminal.
  • ncdu analiza el uso del disco de forma interactiva.
  • gitmoji agrega emojis a los mensajes de commit.
  • pandoc convierte documentos entre diferentes formatos.

Para más información sobre uv en sí, consulte mi Guía rápida para gestionar Python en macOS con uv.

4. Elegir una terminal

La Terminal predeterminada de macOS es suficiente. Utilicé iTerm2 durante años y recientemente pasé a Warp, una terminal basada en Rust con funciones integradas para IA. La elección es personal; ninguna parte posterior de la configuración depende de ella.

Opcional: Configuración de iTerm2

Si decide seguir usando iTerm2, estos son los dos ajustes que siempre modifico:

Habilitar edición de texto natural

  1. Preferencias → Perfiles → Teclas → Asignaciones de teclas
  2. Haga clic en el menú desplegable “Predefinidos…”
  3. Seleccione “Edición de texto natural”

Elegir un tema de colores

  1. Explorar temas en iTerm2-Color-Schemes
  2. Preferencias → Perfiles → Colores → Predefiniciones de color…
  3. Hacer clic en “Importar” y seleccionar el tema descargado.

5. Configurar Zsh

macOS ya incluye Zsh y lo utiliza como shell de inicio predeterminado. Yo empleo la versión incluida con el paquete /bin/zsh; solo se debe instalar la versión de Zsh de Homebrew cuando sea necesario contar con una versión más reciente del código fuente.

Comprobar la versión instalada de Zsh y el shell de inicio actual:

echo "$SHELL"
command -v zsh
zsh --version

Si Zsh está instalado pero no está seleccionado como shell de inicio, cambiarlo por la copia incluida con el paquete:

chsh -s /bin/zsh

Abrir una nueva terminal tras modificar el shell de inicio.

Oh My Zsh añade los valores por defecto y el sistema de complementos que yo utilizo. Su instalador oficial es:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

El proyecto recomienda examinar detenidamente cualquier instalador desconocido antes de ejecutarlo. También indica que un .zshrc existente es renombrado a .zshrc.pre-oh-my-zsh durante la instalación.

6. Agregar complementos para Zsh

Editar el archivo ~/.zshrc para cargar estos complementos:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Eliminar pyenv de la lista de complementos si se omitió la instalación opcional de pyenv.

Existen descripciones de todos ellos en la wiki de complementos de Oh My Zsh.

Los dos últimos requieren una instalación separada:

  • zsh-autosuggestions sugiere comandos basados en el historial mientras se escribe.
  • zsh-syntax-highlighting resalta por colores los comandos al escribirlos, lo que facilita detectar errores tipográficos.

Seguir las instrucciones de instalación indicadas en cada repositorio.

7. Personalizar con Powerlevel10k

Powerlevel10k es el tema de Zsh que uso. Muestra en la barra de estado el directorio de trabajo, el estado de git y el entorno de Python activo, además de disponer de un asistente interactivo para ajustar su apariencia. Las instrucciones de instalación se encuentran en la página de GitHub.

Fuentes en otros editores

Si se utiliza VSCode u otro editor con terminal integrada, configurar la fuente de la terminal para que se muestren correctamente los íconos de Powerlevel10k:

  1. Abrir las opciones del editor.
  2. Buscar terminal.integrated.fontFamily.
  3. Establecerlo en MesloLGS NF (instalado junto con Powerlevel10k).

La configuración completa de fuentes está disponible en la guía de fuentes de Powerlevel10k.

8. Editores e asistentes de IA

Siempre tengo abierto un IDE y uno o dos herramientas de IA funcionando en segundo plano.

IDEs

  • Cursor — una versión derivada de VSCode con programación colaborativa mediante IA integrada.
  • VSCode — el que cuenta con un amplio catálogo de extensiones.

Asistentes de IA

  • OpenAI Codex — el agente de programación de OpenAI.
  • Claude — el asistente de Anthropic; el que utilizo para tareas más complejas.

Actualmente uso Cursor junto con Codex y Claude Code en paralelo.

9. Otros componentes

Algunos elementos adicionales que instalo en cada máquina:

  • GitHub Desktop — cliente gráfico para Git cuando no se desea trabajar desde la línea de comandos.
  • Docker Desktop — el motor de contenedores que utilizo; Podman Desktop es una alternativa.
  • Ollama o LM Studio — para ejecutar modelos de lenguaje grande localmente en el Mac.

10. Esa es la configuración inicial

Eso es lo que instalo en cada MacBook nuevo antes de empezar a trabajar de verdad. Puedes ajustarlo según tus necesidades.

Puntos clave

  1. Se trata de una configuración personal; no representa una base mínima ni universal para macOS. Elimina todo aquello que no utilices.
  2. El paquete /bin/zsh incluido es suficiente para esta configuración. Instala solo la versión de Zsh de Homebrew cuando necesites una versión más reciente específica.
  3. En mi flujo de trabajo diario, uv se encarga ahora de la instalación de Python y de los entornos de proyecto. pyenv sigue siendo opcional para interpretadores CPython compilados a mano o personalizados.
  4. Documenta siempre los comandos de instalación, los archivos de configuración sin datos sensibles, las extensiones del editor y las ubicaciones de los modelos, para que la siguiente configuración sea un proceso mecánico.
