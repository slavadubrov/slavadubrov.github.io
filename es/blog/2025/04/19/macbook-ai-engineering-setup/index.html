Configuración del MacBook para AI Engineering: herramientas y flujo de trabajo en macOS

Viacheslav Dubrov

2025-04-19 · Actualizado 2026-08-16 · 5 min · Herramientas de desarrollo

Traducción automática Este artículo se tradujo automáticamente a partir de la versión original en inglés.

Esta es mi checklist para convertir una instalación limpia de macOS en una estación de trabajo para ingeniería de IA: herramientas de línea de comandos, Homebrew, Python, Docker, valores predeterminados del terminal y configuración del editor.

TL;DR

Homebrew, Python con uv, el Zsh incluido con Oh My Zsh y Powerlevel10k, Docker, mis editores y herramientas de IA locales. Mantén los comandos y los dotfiles bajo control de versiones para que la configuración sea reproducible.

1. Instalar las herramientas de línea de comandos de Xcode

xcode-select --install

Se abrirá un cuadro de diálogo que te guiará durante la instalación.

2. Instalar Homebrew

Homebrew es el gestor de paquetes que uso para todo lo demás de esta lista:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

El instalador explica qué cambios realizará y solicita confirmación. En Apple Silicon, Homebrew usa /opt/homebrew de forma predeterminada. Ejecuta el comando brew shellenv que se muestra al final; Homebrew no añade brew al PATH de tu shell por sí solo.

3. Instalar las herramientas principales

Byte says

Ejecuté el instalador de Homebrew, escribí brew install y obtuve command not found. El instalador muestra esa línea brew shellenv al final por una razón.

brew install openssl readline sqlite3 xz zlib uv htop gitmoji pandoc ncdu tmux

Agrupadas, a grandes rasgos, según su finalidad:

Entorno de Python

Antes de adoptar uv, usaba pyenv para gestionar mis entornos de Python. Ahora uv cubre ese flujo de trabajo diario.

  • uv instala versiones de Python y gestiona entornos de proyecto, dependencias, comandos y lockfiles.
  • pyenv es opcional. Solo lo uso cuando necesito un intérprete compilado desde el código fuente u opciones de compilación personalizadas de CPython que las distribuciones precompiladas de uv no ofrecen.

Instala la versión más reciente de Python gestionada por uv:

uv python install

Este comando instala la versión más reciente de Python disponible para uv en el momento de la configuración. Para una versión específica del proyecto, utiliza el flujo de trabajo de fijación de versiones de la guía enlazada de uv.

Instala pyenv por separado cuando necesites compilar desde el código fuente:

brew install pyenv

Bibliotecas del sistema

  • openssl proporciona compatibilidad con criptografía SSL/TLS.
  • readline añade edición de texto en la línea de comandos.
  • sqlite3 es una base de datos embebida ligera.
  • xz y zlib proporcionan compresión de datos.

Herramientas de productividad

  • htop es un monitor visual del sistema y de los procesos.
  • tmux gestiona varias sesiones de terminal.
  • ncdu analiza interactivamente el uso del disco.
  • gitmoji añade emojis a los mensajes de commit.
  • pandoc convierte documentos entre formatos.

Para obtener más información sobre uv, consulta mi guía rápida para gestionar Python en macOS con uv.

4. Elegir un terminal

El Terminal predeterminado de macOS es suficiente. Durante años usé iTerm2 y recientemente me pasé a Warp, un terminal basado en Rust con funciones de IA integradas. La elección es personal; ninguno de los pasos posteriores depende de ella.

Opcional: configuración de iTerm2

Si decides seguir con iTerm2, estos son los dos ajustes que siempre cambio:

Activar la edición de texto natural

  1. Preferences → Profiles → Keys → Key Mappings
  2. Haz clic en el desplegable Presets…
  3. Selecciona “Natural Text Editing”

Elegir un tema de color

  1. Explora temas en iTerm2-Color-Schemes
  2. Preferencias → Perfiles → Colores → Preajustes de color…
  3. Haz clic en Importar y selecciona el tema que has descargado

5. Configurar Zsh

macOS ya incluye Zsh y lo utiliza como shell de inicio de sesión predeterminado. Yo uso el /bin/zsh incluido; instala el Zsh de Homebrew solo si necesitas una versión upstream más reciente y específica.

Comprueba el Zsh instalado y tu shell de inicio de sesión actual:

echo "$SHELL"
command -v zsh
zsh --version

Si Zsh está instalado, pero no está seleccionado como shell de inicio de sesión, cambia a la copia incluida:

chsh -s /bin/zsh

Abre un terminal nuevo después de cambiar el shell de inicio de sesión.

Oh My Zsh añade los valores predeterminados y el sistema de plugins que uso. Su instalador oficial es:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

El proyecto recomienda inspeccionar cualquier instalador que no conozcas antes de ejecutarlo. También documenta que un .zshrc existente se renombra como .zshrc.pre-oh-my-zsh durante la instalación.

6. Añadir plugins de Zsh

Instala los dos plugins externos en el directorio de plugins personalizados de Oh My Zsh:

git clone https://github.com/zsh-users/zsh-autosuggestions "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions"
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting"

Edita tu ~/.zshrc para cargar estos plugins:

plugins=(
    aws bgnotify brew docker docker-compose
    emoji forklift gcloud git history iterm2
    keychain kubectl macos pre-commit
    pyenv pylint python screen themes
    tmux virtualenv vscode
    zsh-autosuggestions zsh-syntax-highlighting
)

Mantén zsh-syntax-highlighting como último elemento de este array.

Elimina pyenv de la lista de plugins si has omitido la instalación opcional de pyenv.

Las descripciones de todos ellos están en la wiki de plugins de Oh My Zsh.

Los dos últimos requieren una instalación independiente:

  • zsh-autosuggestions sugiere comandos de tu historial mientras escribes.
  • zsh-syntax-highlighting colorea los comandos mientras escribes, lo que facilita detectar errores tipográficos.

Sigue las instrucciones de instalación de cada repositorio.

7. Personalizarlo con Powerlevel10k

Powerlevel10k es el tema de Zsh que uso. Muestra el directorio de trabajo, el estado de git y el entorno de Python activo en el prompt, y cuenta con un asistente interactivo para ajustar su aspecto. Las instrucciones de instalación están en la página de GitHub.

Instalar la fuente de Powerlevel10k

Si usas VS Code con un terminal integrado, instala la fuente recomendada antes de configurar la fuente del terminal. Así los iconos de Powerlevel10k se renderizarán correctamente. p10k configure puede instalar automáticamente la fuente en iTerm2. Para otros terminales, descarga e instala los cuatro archivos TTF de la guía de fuentes de Powerlevel10k.

En VS Code, configura la fuente del terminal como MesloLGS NF:

  1. Abre la configuración de tu editor
  2. Busca terminal.integrated.fontFamily
  3. Establécelo como MesloLGS NF

La configuración completa de la fuente está en la guía de fuentes de Powerlevel10k.

8. Editor y asistentes de IA

Siempre acabo con un IDE abierto y una o dos herramientas de IA ejecutándose al lado.

IDE

  • Cursor — un fork de VS Code con pair programming asistido por IA integrado
  • VS Code — el que cuenta con un catálogo enorme de extensiones

Asistentes de IA

  • OpenAI Codex — el coding agent de OpenAI
  • Claude — el asistente de Anthropic; al que recurro para las tareas más difíciles

Hoy en día, uso Cursor con Codex y Claude Code ejecutándose en paralelo.

9. El resto

Algunos extras que instalo en todos los equipos:

  • GitHub Desktop: cliente visual de Git cuando no quiero pasar a la CLI
  • Docker Desktop: el runtime de contenedores que uso; Podman Desktop es una alternativa
  • Ollama o LM Studio: ejecutar LLM localmente en el Mac

10. Esta es la configuración

Todo lo anterior se instala en cada MacBook nuevo antes de empezar a trabajar en serio. Adáptalo a tus necesidades.

Puntos clave

  1. Esta es una configuración personal, no una base mínima ni universal para macOS. Elimina todo lo que no uses.
  2. El /bin/zsh incluido es suficiente para esta configuración. Instala el Zsh de Homebrew solo cuando necesites una versión upstream más reciente concreta.
  3. En mi flujo de trabajo diario, uv se encarga ahora de instalar Python y gestionar los entornos de proyecto. pyenv sigue siendo opcional para intérpretes de CPython compilados desde el código fuente o personalizados.
  4. Documenta los comandos de instalación, los dotfiles sin secretos, las extensiones del editor y las ubicaciones de los modelos para que la próxima configuración sea mecánica.
